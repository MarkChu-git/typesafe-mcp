# E-Commerce Service

A TypeScript service for managing orders, payments, and refunds.

## Structure

- `src/orders/` - Order creation and management
- `src/payments/` - Payment processing and refunds
- `src/refunds/` - Refund workflow implementation
- `src/notifications/` - Email and notification services
- `src/admin/` - Administrative functions
- `src/utils/` - Utility functions

## Getting Started

```bash
npm install
npm run build
npm run dev
```
